常见问题解答

挂号问题

如何在线预约挂号？ +
您可以通过本网站"就诊服务"页面进行在线预约，或关注微信公众号进行预约挂号。建议提前1-3天预约。
可以挂当天的号吗？ +
可以，但号源有限，建议提前预约。急诊患者可直接到急诊科挂号。
如何取消或改约？ +
请至少提前2小时通过原预约渠道操作。如已过时间，请联系医院服务台。
专家号和普通号区别？ +
专家号由主任医师/副主任医师坐诊；普通号由主治医师坐诊。

就诊问题

门诊时间？ +
周一至周五 08:00-12:00,14:00-17:30；周六上午08:00-12:00；周日及法定节假日休息。
需要带什么资料？ +
首次就诊请携带身份证、医保卡、既往病历和检查报告。
检查需要空腹吗？ +
眼科常规检查不需要空腹。特殊血液检查医生会提前告知。
可以做近视手术吗？ +
18-45岁、度数稳定满2年即可术前检查评估。

费用问题

白内障手术多少钱？ +
根据选择的晶体类型不同，费用在3,000-20,000元不等。医保可报销部分费用。
近视激光手术费用？ +
全飞秒约15,000-18,000元；半飞秒约10,000-13,000元；准分子约6,000-9,000元。
支持哪些支付方式？ +
现金、银行卡、微信支付、支付宝、医保卡结算。

医保问题

哪些项目可以用医保？ +
门诊挂号费、大部分检查费、药品费、住院费用均可按医保政策报销。
异地医保可以直接结算吗？ +
我院支持异地医保直接结算，请携带医保电子凭证或实体卡办理。

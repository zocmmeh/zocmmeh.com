### 步骤 3：ICP 备案（免费，但必须）

**所需材料：**
- [ ] 医院营业执照 / 事业单位法人证书
- [ ] 医疗机构执业许可证
- [ ] 法人身份证正反面
- [ ] 网站负责人身份证正反面
- [ ] 网站负责人手机号（需验证）
- [ ] 域名证书（注册商提供）

**操作流程：**
1. 登录你的云服务商控制台（阿里云/腾讯云）
2. 找到「ICP 备案」入口
3. 填写备案信息：
   - 主体信息：医院名称、统一社会信用代码、地址
   - 网站信息：域名、网站名称、服务内容
   - 负责人信息：姓名、身份证、手机
4. 上传材料照片
5. 提交审核
6. 云服务商初审（1-2个工作日）
7. 管局终审（7-20个工作日）
8. 备案通过，获得备案号

**⚠️ 医疗机构网站额外要求：**
- 可能需要提供《互联网医疗保健信息服务许可证》
- 如果涉及在线问诊/处方，需要《互联网医院许可证》
- 纯信息展示型网站（无在线诊疗）要求相对宽松

**方式 C：宝塔面板（推荐新手）**
1. 服务器安装宝塔面板：https://www.bt.cn
2. 面板中创建网站，绑定域名
3. 通过面板的文件管理器上传文件

### 步骤 5：域名解析

1. 登录域名注册商控制台
2. 找到域名解析设置
3. 添加 A 记录：
   - 主机记录：`@`
   - 记录值：服务器 IP 地址
   - TTL：默认（10分钟）
4. 添加 CNAME 记录（可选，用于 www）：
   - 主机记录：`www`
   - 记录值：你的域名
5. 等待 DNS 生效（通常 10 分钟 - 2 小时）

### 步骤 6：配置 HTTPS（免费）

1. 申请免费 SSL 证书：Let's Encrypt
2. 宝塔面板：网站设置 → SSL → Let's Encrypt → 申请
3. 开启强制 HTTPS

## 📋 编辑权限管控方案

### 方案 1：Git 版本控制（推荐技术团队）

```
权限级别：
├── 管理员（院长/信息科主任）
│   └── 合并代码、发布上线、管理成员
├── 编辑者（信息科/宣传科）
│   └── 提交修改内容
└── 查看者（其他科室）
    └── 只能查看，不能修改
```

**设置方法：**
1. 在 GitHub/Gitee 创建私有仓库
2. Settings → Collaborators → 添加成员
3. 分配权限：Admin / Write / Read
4. 修改流程：编辑者提交 → 管理员审核 → 合并上线

### 方案 2：宝塔面板 + 简易CMS（推荐非技术团队）

1. 安装宝塔面板
2. 面板中创建子账号（不同权限）
3. 使用 Typecho / WordPress 等轻量 CMS
4. 通过 CMS 后台管理内容
5. 不同角色分配不同权限：
   - 超级管理员：全站管理
   - 编辑：只能编辑指定栏目
   - 作者：只能投稿

### 方案 3：宝塔面板 + 文件权限（最简单）

```
通过宝塔面板管理不同人员的文件访问权限：

信息科管理员（你）→ 宝塔面板完整权限
宣传科编辑人  → 只能访问 /images/ 和指定 HTML 文件
其他科室     → 无权限，通过提交表单申请修改
```

**操作：**
1. 宝塔面板 → 安全 → 设置面板登录密码
2. 宝塔面板 → 设置 → 创建子账户（限制权限）
3. 重要文件设置只读权限

### 方案 4：在线协作编辑（最方便）

使用在线工具直接编辑 HTML：
- **Gitee Pages**（国内版 GitHub，访问快）
- **Coding Pages**（腾讯旗下）
- **Cloudflare Pages**

修改流程：
```
科室提出修改需求（微信/邮件）
        ↓
信息科登录在线平台
        ↓
在线编辑对应文件
        ↓
自动发布上线（或审核后发布）
```
